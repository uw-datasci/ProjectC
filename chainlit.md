# Welcome to Project C

This is the interactive test environment for our **Therapy-Style Conversational Agent**. 

This agent is designed as a *high-risk test environment* for studying prompt robustness, safety boundaries, and failure modes under benign, ambiguous, and adversarial user inputs.

## Important Notes 
- The agent's role is to provide neutral, reflective, and non-directive conversation.
- It **will not** provide medical, psychological, or psychiatric advice, diagnose conditions, or engage in crisis intervention.
- The agent prioritizes **safety boundaries and alignment** over simple user satisfaction or task completion.

*Feel free to start typing your prompt below to interact with the agent!*
